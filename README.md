# Kingroon KP3S Pro — Klipper configuration and profiles

Репозиторий хранит рабочие конфигурации принтера Kingroon KP3S Pro и экспортированные профили Bambu Studio.

## Структура

- `klipper-config/` — актуальная копия конфигурации с хоста Klipper. Не редактируйте эти файлы на GitHub во время работы принтера: сначала меняйте конфигурацию через Fluidd, затем обновляйте резервную копию.
- `bambu-studio-profiles/printers/` — экспортированные профили принтера из Bambu Studio.
- `bambu-studio-profiles/filaments/` — экспортированные профили филамента.
- `bambu-studio-profiles/processes/` — экспортированные профили процесса/печати.

## Как добавлять профиль из Bambu Studio

Экспортируйте профиль из Bambu Studio и положите файл в соответствующую папку. Используйте понятное имя, например `Kingroon-KP3S-Pro-0.4mm.json` или `PLA-Silk-205C.json`.

## Безопасность

Репозиторий открытый. Не добавляйте пароли, токены, IP-адреса, приватные ключи, логи или дампы с персональными данными.
