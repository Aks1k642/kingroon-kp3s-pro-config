# Kingroon KP3S Pro — конфигурация, профили и история доработок

Здесь хранится рабочая конфигурация принтера, экспортированные штатными средствами профили Bambu Studio, история обслуживания и материалы по доработкам.

## Что лежит в папках

| Папка | Что в ней хранится |
| --- | --- |
| [`klipper-config/`](klipper-config/) | Резервная копия действующих конфигов Klipper: кинематика, нагреватели, макросы, 3DTouch и сетка стола. Это снимок настроек принтера, а не место для редактирования «на живую». |
| [`bambu-studio-profiles/`](bambu-studio-profiles/) | Пакеты предустановок, экспортированные из Bambu Studio: профиль принтера, филамента и процесса печати. |
| [`docs/`](docs/) | Документация проекта: что уже изменено, текущий план, статистика печати и обслуживание. |
| [`modifications/`](modifications/) | Карточки установленных и планируемых модификаций, ссылки на авторские модели и только собственные правки к ним. |

## Важные правила

- Изменения принтера сначала выполняются через Fluidd/Klipper, затем актуальная конфигурация сохраняется сюда отдельным коммитом.
- Профили Bambu Studio экспортируются через **Файл → Экспорт → Экспортировать пакет предустановок** и кладутся без ручного изменения содержимого.
- Репозиторий открытый: не добавляйте пароли, токены, приватные ключи, логи, IP-адреса и персональные данные.
- Сторонние модели не копируйте без разрешения лицензии. Для них достаточно ссылки, автора, лицензии и описания собственных изменений.
