## Параметры для следующего сеанса

- Датчик `^PC4 / PA8`, offsets `26,1`; оба `pin_up_...: False`, `probe_with_touch_mode: False`.
- Z: диапазон `-5…180`, отрицательное направление хоминга, скорость `12.5 мм/с`, retract `0` (один проход).
- Safe home: сопло `74,99`, датчик `100,100`; подъём `10 мм` со скоростью `20 мм/с`.
- Временной блокировки G28 из старого чата **нет**. START_PRINT вызывает штатный G28 и загружает карту `default`.
- Старые offsets `-40,0`, home `130,90`, touch mode True и диагностическая скорость Z `2 мм/с` не описывают текущий конфиг.
- Google-таблица и «памятка качества» отменены владельцем; параметры планируется хранить профилями Bambu Studio.
