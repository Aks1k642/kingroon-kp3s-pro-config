# Журнал изменений

Фиксируем только изменения, которые действительно применены к принтеру или его профилям.

## 2026-10-18 — сверка файлов хоста и истории Git

- Владелец подтвердил работу BLTouch. Принтер при аудите выключен; движения, нагрев, изменение рабочих конфигов и перезапуски не выполнялись.
- С хоста сохранены `z_offset: -0.300` и новая сетка default 5×5 с перепадом 3.803750 мм. Предыдущий Git HEAD `041ab3b` содержал offset `0` и другую сетку (перепад 1.475000 мм). Причины промежуточных действий не известны.
- Синхронизирован Macros.cfg: команды совпадали, отличались комментарии/оформление. Добавлен подключаемый fluidd.cfg с лицензией и точным upstream-коммитом; файлы хоста не менялись.
- Сохранены параметры сборки MCU; это `.config`, не образ прошивки. Обновлены STATUS, статистика, аудит, разбор 10 коммитов и инструкции продолжения на другом ПК.
- Найденные риски END_PRINT и большой перепад карты записаны для отдельной проверки; рабочие настройки автоматически не исправлялись. Старой блокировки G28 в текущем конфиге нет.
- Разрешены ZIP-экспорты внутри каталога Bambu Studio в `.gitignore`.
- Для текстовых файлов заданы окончания строк LF, чтобы перенос между Windows/Linux не менял снимки и контрольные суммы.
- В manifest раздельно записаны контрольные суммы исходных байтов хоста и нормализованных LF-файлов Git; три файла хоста используют CRLF.

## 2026-10-17 — последующая серия настроек Z

После первоначального снимка записаны offsets `-2.139`, `-3.5`, `1.2`, `-0.2`, `0`; минимум Z расширен с `-3` до `-5`. Причины и физические результаты не указаны в коммитах. Подробный разбор: [COMMIT_HISTORY.md](COMMIT_HISTORY.md).

## 2026-10-17 — Klipper и 3DTouch

- Настроен 3DTouch/BLTouch как Z-endstop.
- В первоначальном снимке записаны `x_offset: 26`, `y_offset: 1`, `z_offset: -1.839`. Последнее значение историческое, не актуальный Z-offset.
- Настроен безопасный хоуминг Z в точке сопла `X74 Y99`; датчик при этом находится над центром стола `X100 Y100`.
- Скорость хоуминга Z установлена на 12.5 мм/с, повторный проход отключён.
- Создана сетка стола `default` размером 5×5; она загружается макросом `START_PRINT` после `G28`.
