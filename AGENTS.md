# Работа с Kingroon KP3S Pro

- Владелец 18.10.2026 уточнил точную модель: **KP3S Pro S1**. Принтер перевозили и сейчас требуется частичная повторная сборка. Размеры пружин и винтов стола пока не измерены; не обещайте совместимость покупок по названию модели.
- Начинайте с `docs/STATUS.md`, `docs/CHANGELOG.md`, последнего аудита и `git status`/`git log`. Файлы хоста могут быть новее Git.
- До изменений скачайте текущие конфиги, включая блок `SAVE_CONFIG`, и сравните с Git. Не восстанавливайте поверх них старые настройки из чата.
- Изменения рабочей конфигурации сначала выполняются и проверяются на принтере, затем копируются сюда. При аудите не меняйте пины, смещения, режимы датчика и скорости автоматически.
- Ранее Z не останавливалась после касания 3DTouch. Для дистанционного движения/нагрева нужны актуальная команда пользователя и присутствие человека у принтера. Старое разрешение на тест не означает готовность к новому движению.
- `Ready`, `homed_axes=xyz` и смена светодиода не доказывают остановку оси датчиком. Записывайте наблюдение владельца; не объявляйте тест успешным по этим полям.
- Не объясняйте продолжение движения вторым проходом без подтверждения. Теперь `homing_retract_dist: 0`: проход G28 один. `samples: 2` относится к отдельным измерениям probe.
- Оба `pin_up_...` сейчас `False`, `probe_with_touch_mode: False`. Это настройки работающего по сообщению владельца клона. Причина прежнего отказа окончательно не установлена; не возвращайте старые варианты из чата.
- Выключенный принтер при включённом ноутбуке означает отсутствие MCU. Это не основание менять конфиг, перепрошивать плату или перезапускать сервисы.
- Снимок файла, запуск ПО и физически проверенный результат отмечайте раздельно. Не записывайте неизвестные измерения и причины откатов как факты.
- Репозиторий открытый. Пароли, токены, ключи, адреса сети, логи, дампы API и персональные данные подключения передаются отдельно и не коммитятся.
- Профили Bambu Studio сохраняйте штатными экспортами. Google-таблица и «памятка качества» отменены владельцем, возвращать их не нужно.
