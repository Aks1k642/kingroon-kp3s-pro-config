# Конфигурация Klipper

В этой папке лежит резервная копия файлов конфигурации, которые сейчас используются принтером.

Сверено с файлами хоста **18 октября 2026** при выключенном принтере. Содержание файлов подтверждено; хоминг, нагрев и печать повторно не проверялись. См. [аудит](../docs/AUDIT-2026-10-18.md).

## Что здесь хранить

- `printer.cfg` — основной файл: общие параметры принтера, 3DTouch/BLTouch, карта стола и подключения остальных файлов.
- `stepper.cfg` — двигатели и концевики осей X, Y, Z; безопасный хоуминг Z.
- `extruder.cfg`, `bed.cfg`, `fan.cfg`, `thermistor.cfg` — нагреватели, вентиляторы и датчики температуры.
- `Macros.cfg` — макросы старта и завершения печати.
- `tmc.cfg` — настройки драйверов TMC, если они используются.
- `fluidd.cfg` — снимок клиентских макросов Fluidd. На хосте это символическая ссылка в установленный fluidd-config, в резервной копии — обычный файл.

Сейчас `tmc.cfg` полностью закомментирован: UART-настройки из него не применяются.

`fluidd.cfg` сохранён без изменений из [fluidd-core/fluidd-config, коммит 807175d72e3a00cdc6b5e249444a4630e1e03a55](https://github.com/fluidd-core/fluidd-config/blob/807175d72e3a00cdc6b5e249444a4630e1e03a55/fluidd.cfg). Copyright и уведомление GPL сохранены; [текст GPLv3](../LICENSES/fluidd-config-GPL-3.0.txt) приложен. Не заменяйте рабочую символическую ссылку копией без необходимости.

Это не резервная копия всего хоста. Moonraker, настройки интерфейса, базы истории/Spoolman и данные доступа сохраняются отдельно; необезличенные файлы не публикуются в открытом Git.

## Как обновлять резервную копию

1. Внести и проверить изменение в Fluidd/Klipper.
2. Скопировать актуальные файлы с хоста принтера в эту папку.
3. Описать изменение в `docs/CHANGELOG.md`.
4. Сделать отдельный коммит с понятным названием.

Не кладите сюда логи, временные копии и файлы с паролями.
