# Профили Bambu Studio

Здесь хранятся **экспортированные пакеты предустановок**. Их нужно получать штатной командой Bambu Studio: **Файл → Экспорт → Экспортировать пакет предустановок**.

## Папки

- `printers/` — профили принтера: габариты, сопло, стартовый G-code, скорости, ускорения и прочие настройки конкретного Kingroon KP3S Pro.
- `filaments/` — профили прутка: PLA, PETG, ABS и другие материалы с температурами, обдувом и коэффициентами потока.
- `processes/` — профили процесса печати: высота слоя, заполнение, стенки, поддержки, скорости и качество.

## Имена файлов

Давайте файлам читаемые имена: `Kingroon-KP3S-Pro-0.4mm`, `PLA-Silk-205C`, `PETG-0.20mm-Quality`.

Не изменяйте содержимое экспортированного пакета вручную: так его можно будет без сюрпризов импортировать обратно в Bambu Studio.
