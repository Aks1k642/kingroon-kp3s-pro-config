# Параметры сборки MCU

`klipper-build.config` — неизменённая копия `.config` установленного дерева Klipper, прочитанная 18 октября 2026. Это не бинарник и не доказательство того, что текущая прошивка собрана именно из этого файла. Прошивка аудитом не менялась.

Выбраны STM32F103 (`stm32f103xe`), 72 МГц, кварц 8 МГц, смещение приложения `0x7000` (28 КиБ), USART3, 250000 бод, начальные пины `!PC6, !PD13`. Конфигурация использует последовательный порт MCU через USB–serial хоста.

Последнее ранее успешное соединение в журнале сообщает MCU `v0.13.0-745-gf0892d82`; host Klipper — `v0.13.0-762-g9871eeef`. Маркировка и ревизия платы физически не проверялись. Перед восстановлением прошивки отдельно подтвердите MCU, загрузчик и связь по реальной плате.
